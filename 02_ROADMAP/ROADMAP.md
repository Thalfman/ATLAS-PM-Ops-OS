# ROADMAP.md

## Roadmap purpose

This roadmap sequences ATLAS PM/Ops OS from safe scaffold to an employer-migratable operating system. Dates are intentionally omitted until Tom decides on an execution calendar. The order matters more than the calendar.

## Status key

- **Complete:** usable starter version exists.
- **In progress:** active build area.
- **Planned:** sequenced but not yet built.
- **Deferred:** intentionally held until employer approvals or real environment details are available.

## First three practical build moves

1. **Harden continuity.** Make it easy to resume work from `MASTER_CONTEXT.md` and `SESSION_HANDOFF.md` without restating the project.
2. **Prioritize artifacts.** Identify which templates and workflows will help Tom provide value fastest during clearance-limited onboarding.
3. **Build governance first.** Make sure AI-enabled workflow proposals are safe, credible, and approval-friendly before building demos.

## Decision gates

### Gate A: Pre-start safety gate

Before creating any demo, prompt, or workflow, confirm that all inputs are synthetic, public, generic, or fictional.

### Gate B: Employer-use gate

Before using any ATLAS artifact at work, confirm:

- The tool is approved.
- The data is approved for that tool.
- The workflow does not bypass employer systems.
- A human remains responsible for review and decisions.
- No classified, CUI, ITAR, proprietary, customer, contract, schedule, finance, or technical data is placed into unapproved tools.

### Gate C: Automation gate

Before automating anything, confirm that the manual workflow is stable, understood, and approved. ATLAS should prove operating value before adding technical integrations.

## Roadmap notes

ATLAS is built for durable PM/Ops leverage. The immediate aim is not to produce a large library; it is to produce a small set of reliable artifacts that help Tom listen well, ask strong questions, document process gaps, improve reporting quality, and propose responsible AI-enabled improvements in a conservative environment.
