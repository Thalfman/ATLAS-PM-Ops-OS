## How to use

1. Start with the next unfinished phase.
2. Open the matching `PHASE_##_*.md` file.
3. Copy the text inside the `Copy-paste prompt` block.
4. Run that prompt in the working AI environment.
5. Let the session update `09_HANDOFFS/SESSION_HANDOFF.md` before moving to the next phase.

## Standing safety rule

Do not use real employer data, classified data, CUI, ITAR/export-controlled data, proprietary data, customer data, contract data, internal schedules, internal financials, internal technical documents, real meeting notes, real project accounting exports, or real Microsoft Project files from employer systems in personal or unapproved tools.

Use only synthetic, public, generic, fictional, or explicitly approved data paths.

## Working principle

ATLAS is Markdown-first. These prompts should create or refine Markdown artifacts, templates, workflows, governance notes, prompts, demo packs, and handoff files. They should not create an app, package, database, API, or deployment scaffold unless Tom explicitly asks later.
